# AI-2199 — The Singularity Countdown

A cinematic static web app about the symbolic countdown to 1 January 2199 and the question of machine intelligence.

## Includes
- Live countdown to 2199-01-01 UTC
- Viral share/copy flow
- Matrix-style code rain
- Terminal easter egg and commands
- Singularity explainer
- Matrix Wiki
- Timeline
- Manifesto
- FAQ + About
- PWA manifest
- SEO metadata, robots.txt and sitemap.xml
- Links to https://matrix-codes.netlify.app/ and https://matrix-mind.netlify.app/

## Run
```bash
npm install
npm run dev
```

## Deploy
Works as a normal Vite static site on Netlify, Vercel or similar.

The 2199 date is intentionally presented as a symbolic thought experiment, not a scientific prediction.
